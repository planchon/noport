## Installation 

To install `noport` you just need to run the following command:

```bash
curl -fsSL https://get.noport.dev | sh
```

## AI assisted installation

For all the vibe coders out there, `noport` comes with an AI ready skill, this skill will handle all the installation and repository adaptation. 

```bash 
npx skills add planchon/noport
```

and then ask politely your agent to install everything for you.

```bash
coding-agent please install noport bro
```

## From source

To build noport from source, you need to have installed all the rust toolchain.

```bash
git clone https://github.com/planchon/noport
cargo build --release
cp target/release/noport /usr/local/bin
```
