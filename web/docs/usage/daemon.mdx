<Note>
If you run the `noport` command without a daemon running, it will start one for you.
</Note>

## Proxy configuration
### `start` the daemon
Start the daemon and customize the proxy behavior.

| Flags | Description | Default value |
| :----------- | :------------ | :------------ |
| ``--foreground`` | Start the daemon in the foreground | false |
| ``--port`` | Change the port the proxy will listen on | 2828 |
| ``--tld`` | Change the TLD | .localhost |
| ``--https`` | Enable HTTPS proxy and HTTP2 server | false |

<Warning>
`noport` can asked for sudo access when : `port < 1024` or when using a custom `tld` 
</Warning>

`https` can be run on any port, but if you want to completly remove the port in the browser, `noport` will ask for sudo access (to run the proxy on the port 443)

### `stop` the daemon
Stop the proxy and the daemon. **Does not kill** your application.
